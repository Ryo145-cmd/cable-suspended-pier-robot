# 棄てた案と棄てた理由

- **放置時の自動ロック（一定時間操作がなければ非常停止）**
  → ウォームギアで保持するので停止中に危険はなく、操作の手間が増えるだけ
- **4本のワイヤ長をソフトで同期**
  → エンコーダなしでは繰り出し量が測れず不可能。ワイヤ調整モードで手で合わせる
- **IH装置本体をアルミで覆うノイズ対策**
  → 不可（IH の動作・冷却に影響する）。代わりに制御基板側をアルミ板＋1点接地で対策する
- **生存確認に本体デバイスのイベントを使う**
  → スティックやボタンが変化したときしか出ないので、静止操作中に途絶と誤判定する。モーションセンサを使う
- **IBT-2 の VCC を 5V にする**
  → 74HC244 の H 判定が 3.5V 以上になり Pi の 3.3V 出力で不安定
- **pip でシステムにライブラリを入れる**
  → 最近の Raspberry Pi OS ではエラーになる。apt を使う
