# レール固定マグネットの吸着不足（2026-10-27 検討メモ）

## 状況
- 試験体：プレートガーダー（I桁）。垂直補剛材の間、**上フランジの下面（天井面）**にレールを固定
- マグネット：カネテック 電磁ホルダ KLRM40B（吸着力 220N / 24V 0.09A / 0.15kg）× 4、**24V** で駆動
- 結果：くっついたが弱く、**はがれた**（ずり落ちではない）
- 仮説：塗膜の影響

写真：`images/concept_slide11.png`（構想図）、`images/test_girder.png`（試験体）、`images/test_setup.png`（取付状態）

## 考えられる原因
天井面なので荷重は真下＝マグネットが最も得意な垂直方向。それでもはがれた理由として：
1. **塗膜＝エアギャップ**：φ40 クラスの電磁ホルダは磁束が浅く、0.1〜0.3mm のすき間で吸着力が数分の一になることがある。重防食塗装は総膜厚 250μm 前後が多い（カタログ値は研削面・全面密着の条件）
2. **荷重の偏り・こじり**：レールのたわみやランナー位置で、ワイヤに近い1個に荷重が集中 → そこが端から浮く → 残りに荷重が移って連鎖的にはがれる
3. **当たり面**：フランジ下面の腹板側はすみ肉溶接ビード、塗料のたれ、フランジの反り
4. **動的荷重**：モータ起動・停止、ワイヤ調整時の衝撃

## 試験方法（塗装試験体がなくても可）
塗膜は磁気的にはすき間と同じなので、鋼板＋非磁性シムで再現する。
- 鋼板：厚さ 6〜10mm 以上（薄いと磁気飽和で低く出る）
- シム：PET/OHP フィルム、ポリイミドテープ、樹脂カラーシム（すきまゲージ・ステンレスシムは磁性のものがあるので不可、紙はつぶれるので不可）
- 測定：デジタル吊りはかり or プッシュプルゲージ（ピークホールド）、マイクロメータ、テスタ
1. 鋼板の油・さびを除去。マグネット端子電圧を記録（24V）
2. シム 0 / 50 / 100 / 150 / 200 / 300 / 400 / 500 μm で、面に垂直にゆっくり引き、はがれた瞬間の値を各3〜5回
3. 「すき間–吸着力」グラフを作る
4. 引く位置を中心から 10〜20mm ずらして（こじり）も測る
5. 実レール（マグネット4個）で、シムを挟んで実荷重を吊る
6. 試験体の上フランジ下面の膜厚を電磁式膜厚計で測り、グラフに当てはめる。同じ場所で実際に引きはがし力を測って一致を確認

判定の目安：実荷重（IHヘッド＋水入りホース＋動的荷重込み）の **3倍以上**。

## 対策の候補
- マグネットを1個ずつ首振り＋ばねで取り付けて荷重を均等に
- ワイヤ荷重点（ランナー走行範囲）の真上にマグネットを配置し、レールのたわみを減らす
- 固定位置だけ塗膜を除去（塗替え工事なのでいずれ剥がす面。施工順序と発注者の了解が前提）
- 大型・極間の広いマグネット、永久磁石スイッチ式
- **ビームクランプで上フランジの縁をつかむ**（塗膜の影響なし。最も確実）
- いずれの場合も、マグネットだけに頼らず落下防止のバックアップ（親綱など）を付ける
- マグネットは高温で磁力が急低下する。IH加熱（〜200℃）を近くで行わない
